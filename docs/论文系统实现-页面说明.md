## 论文对应 5.5.6：球员数据分析页面实现

球员数据分析页面对应前端 `front/src/views/PlayerAnalysis.vue` 与 `front/src/views/Prediction.vue`。其中，`PlayerAnalysis.vue` 作为页面容器负责呈现标题“表现预测中心”，并将核心分析界面以内嵌方式交给 `Prediction.vue` 渲染；前端路由在 `front/src/router/index.ts` 中注册为 `/players`。因此，该页面的功能定位并不是简单展示球员静态信息，而是围绕单个球员完成“检索、查看、预测、解释”一体化分析，帮助用户从历史赛季表现出发，进一步观察下一场表现预测、赛季走势变化和关键影响因素。

从页面功能设计看，界面整体分为左右两个主要区域。左侧区域用于球员搜索与选择，用户可以输入姓名关键字调用搜索功能，列表中展示球员姓名、所属球队以及场均得分、篮板、助攻等基础统计，并通过“选择”按钮锁定分析对象。右侧区域在选中球员后展示基础数据概览，包括场均得分、场均篮板和场均助攻；用户点击“生成即时预测”后，页面会展示该球员下一场比赛的预测得分、预测篮板、预测助攻以及模型置信度。除此之外，页面下方还通过标签页进一步提供“赛季趋势预测”和“模型可解释性”两类深度分析能力，使球员分析不再停留于单次预测结果，而是形成短期预测与长期趋势结合的完整分析链路。

从数据交互实现看，页面主要依赖四组接口。其一，前端通过 `GET /api/players` 获取球员列表与基础统计信息，对应后端 `backend-spring/src/main/java/com/nba/backend/controller/PlayerController.java` 中的球员查询接口，核心封装逻辑位于 `backend-spring/src/main/java/com/nba/backend/service/NbaDataService.java` 的 `searchPlayers()` 方法。该方法优先结合 `fact_player_season`、`dim_player` 和 `fact_player_game` 组织球员最近赛季统计、位置与球队信息。其二，点击即时预测后，前端调用 `POST /api/prediction/player`，后端由 `PredictionController` 转入 `NbaDataService.predictPlayer()` 处理；该逻辑优先读取 `fact_player_season` 中最近赛季的场均得分、篮板和助攻数据，再生成下一场表现预测。其三，赛季趋势分析通过 `POST /api/prediction/season` 获取，实际由 `NbaDataService.predictSeasonTrend()` 调用 `playerSeasonHistory()` 读取球员历史赛季序列，并在此基础上生成未来两个赛季的趋势点。其四，模型解释能力通过 `GET /api/prediction/explain/player` 提供，底层由 `NbaDataService.explainPrediction()` 综合最近赛季得分趋势、组织能力贡献、篮板稳定性以及球队近期状态等因素，构造可解释性分析结果。上述接口协议均可在 `front/docs/API_CONTRACT.md` 中找到对应定义。

从可视化呈现方式看，该页面并未采用单一数据表输出，而是通过多种界面元素增强分析表达。即时预测结果通过数据卡片高亮展示预测得分、篮板与助攻，置信度则以进度条形式呈现，使预测强弱能够被快速感知。赛季趋势部分使用 ECharts 绘制折线图，将历史数据与预测数据放在同一坐标系中对比展示，便于观察球员能力变化趋势。模型可解释性部分则使用横向柱状图呈现各个影响因子的贡献方向和贡献大小，并通过颜色区分正向贡献和负向影响，从而提升结果解释的直观性和可读性。页面整体交互基于 Vue 3 与 Element Plus 实现，图表渲染依赖 ECharts，后端则通过 Spring Boot 提供 RESTful API 支撑数据请求。

综合来看，球员数据分析页面已经实现了从球员检索、基础数据查看、下一场表现预测到赛季趋势分析与模型解释输出的完整闭环。该实现既保证了页面交互的直观性，也使球员分析结果具备一定的预测性与解释性，能够为用户提供较为完整的球员表现分析工具。
